Detailed Description

Hlavní aplikační soubor FM Rádia.

Tento soubor obsahuje vstupní bod programu (main) a řídící logiku celého zařízení. Propojuje nízkoúrovňové ovladače (twi, si4703, oled, btns) do funkčního celku.

Function Documentation

◆ automaticke_ladeni()

void automaticke_ladeni ( void )

Provede automatické prohledání celého pásma (Scan).

  • Funkce postupně ladí nahoru (SeekUp). Pokud najde stanici s RSSI vyšším než MIN_RSSI_THRESHOLD, uloží ji do pole stanice. Průběh je vypisován na UART a zobrazován na OLED.

◆ main()

int main ( void )

Vstupní bod programu (Main Loop).

  • 1. Inicializuje periferie (UART, I2C, OLED, Buttons).
  1. Spustí automaticke_ladeni().
  2. Vstupuje do nekonečné smyčky:
  • Čte tlačítka (S1-S5) a reaguje na ně.
  • Periodicky (neblokujícím způsobem) volá si4703_process_rds().
  • Aktualizuje displej při změně stavu nebo RDS dat.

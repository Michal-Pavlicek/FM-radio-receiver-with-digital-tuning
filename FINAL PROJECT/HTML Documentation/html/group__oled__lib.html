Detailed Description

Knihovna pro grafické OLED displeje (SSD1306/SH1106).

#include "oled.h"
oled.h

Tato knihovna poskytuje funkce pro ovládání monochromatických OLED displejů připojených přes I2C nebo SPI. Podporuje textový i grafický režim. V grafickém režimu využívá "frame buffer" v RAM mikrokontroléru.

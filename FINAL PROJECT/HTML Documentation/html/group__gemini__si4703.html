Detailed Description

Ovladač pro FM tuner Si4703.

#include "si4703.h"
si4703.h

Knihovna zajišťuje komunikaci s čipem Si4703 přes I2C sběrnici. Podporuje nastavení frekvence, automatické ladění (Seek), ovládání hlasitosti a neblokující čtení RDS dat (název stanice, radiotext).

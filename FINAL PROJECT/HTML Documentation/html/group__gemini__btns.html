Detailed Description

Knihovna pro obsluhu analogových tlačítek přes ADC.

#include "btns.h"
btns.h

Tato knihovna umožňuje čtení stavu tlačítek zapojených na odporový dělič (Analog Keypad) připojený k ADC převodníku. Zahrnuje funkce pro inicializaci, raw čtení a čtení s ošetřením zákmitsů (debounce).

Function Documentation

◆ buttons_check_press()

ButtonID buttons_check_press ( void )

Zjišťuje stisk tlačítka s ošetřením zákmitsů (debounce).

Returns
ID tlačítka pouze při novém stisku, jinak BTN_NONE.
Note
Funkce je blokující (obsahuje _delay_ms) v momentě detekce změny. Implementuje logiku "state change detection" - vrátí tlačítko jen jednou při stisku, neopakuje hodnotu při držení.
